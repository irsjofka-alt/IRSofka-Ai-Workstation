# Memory Index Template (`brain/memory/MEMORY.md`)

Copy this file to `~/.ai-station/brain/memory/MEMORY.md` on the target host, and populate only
the index lines. Do not copy raw memory content from other machines — only the rules below are portable.

## Contract

Write target for long-term memory: `~/.ai-station/brain/memory/<category>/`.
One topic = one `.md` file. There is no limit on the number of files; the constraint is the number
of files **read simultaneously into context**.

Categories used by this workstation:

```
memory/profile/     Operator identity, working style, custom preferences
memory/hardware/    Hardware specifications, VRAM/RAM limits, disk partitions
memory/projects/    Project states + handoff_* files generated by auto_handoff.py
memory/incidents/   error_tracker.json and self-healing audit logs
memory/reflections/ Behavioral adaptations and lessons learned from past errors
memory/legacy/      Archived memories from prior hosts (read LEGACY_MAP.md first; paths are inactive)
```

## How to Author an Index Entry

```
### 1. User Profile & Habits (`memory/profile/`)
- [user_preferences.md](user_preferences.md) — Single sentence explaining what the reader gains from opening this file.
```

The index entry must provide sufficient detail to decide *whether to open the file*, without needing
to open it beforehand. If two sentences are required, the file is too large and should be split.

## Selective Loading Rules (Non-Negotiable)

1. **Never read the entire memory directory into context.** Read the index, select one line, open one file.
2. Memory is reference knowledge, not real-time evidence. For factual current state (last action,
   active quests, message queues), query PostgreSQL `irsofka_ai_workstation` or run `ai-station recovery 40`.
3. Writing a memory file without indexing it = the memory will never be read. The index is the single entry point.
4. If a memory file conflicts with database records, the database wins. Update the memory, not the database.
5. Contents of `memory/` are never committed to public git. The repository contains only this template.
